# Personal Academic Website Starter

This is a lightweight static academic website. Open `index.html` in a browser to preview it locally, then edit the placeholders with your real details.

## Personalize

- Replace `Your Name`, department, university, and short research summary in `index.html`.
- Replace `assets/profile-placeholder.svg` with your real headshot. If you use `headshot.jpg`, update the `img src` in `index.html`.
- Add your publications, talks, teaching, and links.
- Put your CV at `cv.pdf`, or change the CV link to an external URL.

## Publish With GitHub Pages

1. Create a repository named `your-username.github.io`.
2. Upload these files to the repository root.
3. In GitHub, open Settings, then Pages, and publish from the main branch.
4. Your site will be available at `https://your-username.github.io/`.

## Optional Next Step

For a more automated publication list, keep your papers in a BibTeX file and generate the publications section from it.
